# Team photos

Drop your photos in this folder using these exact filenames:

- `phone-myat-min.jpg` — Phone Myat Min
- `htoo-myat-zaw.jpg` — Htoo Myat Zaw
- `nyan-ye-lin.jpg` — Nyan Ye Lin

## Tips
- Use square photos (1:1 aspect ratio), at least 400×400 px for a crisp look.
- JPG, PNG or WEBP are all fine. If you change the extension, also update the
  `src="images/team/...jpg"` reference in `about.html`.
- Until a photo is added, the card automatically shows the member's
  initials on a coloured circle.
